# 萜类边界情况优化总结

## 优化时间
2026-01-16

## 问题分析

### 原始边界案例测试结果（优化前）
- **成功率**: 60.9% (14/23)
- **假阳性**: 3个（萜类酸被误判）
- **假阴性**: 6个（复杂萜类漏检）

### 主要问题

#### 1. 假阳性问题（3个）
**问题**: 萜类酸（含羧酸基团）被误判为萜类
- 脱落酸 (ABA) - C15降萜+羧酸
- 植烷酸 - C20二萜酸
- 降植烷酸 - C19降萜酸

**原因**: 没有羧酸排除逻辑

#### 2. 假阴性问题（6个）
**评分接近阈值但未通过**:
- 京尼平苷 - 0.227（环烯醚萜糖苷，高氧比例）
- 皮质醇 - 0.391（甾体激素，接近0.40阈值）
- 雌二醇 - 0.347（甾体激素，芳香化）
- 紫杉醇 - 0.280（复杂二萜，多酯基）
- 百里酚 - 0.398（芳香化单萜）
- 香芹酚 - 0.403（芳香化单萜）

**原因**:
1. 氧比例惩罚过严
2. 甾体骨架模式不足
3. 芳香环比例检查过严
4. 碳比例要求过严

## 实施的优化

### 1. 羧酸排除逻辑 ✅

**添加位置**: `_TERPENOID_EXCLUSION_PATTERNS`

```python
"carboxylic_acid": "C(=O)[OH]",
```

**惩罚策略**: 强惩罚（0.4），萜类酸不应被识别为萜类

**效果**:
- ✅ 脱落酸 (ABA): 从True → False (正确排除)
- ✅ 植烷酸: 从True → False (正确排除)
- ✅ 降植烷酸: 从True → False (正确排除)

### 2. 增强甾体骨架检测 ✅

**新增SMARTS模式**:
```python
"pregnane_core": "CC(=O)CC1C2CCC3C4CCC(C(C)(C)C4)CC3C2CC1",
"cortisol_like": "CC12CCC(=O)C=C1CCC1C2C(O)CC2(C)C(C(=O)CO)CCC12",
"estrane_core": "CC12CCC3C(CCC4=CC(=O)CCC34C)C1CCC2O",
"steroid_fused_4rings": "C1CCC2C(C1)CCC1C2CCC2CCCC12",
```

**效果**:
- ⚠️ 皮质醇/雌二醇仍需进一步优化骨架模式

### 3. 芳香化单萜优化 ✅

**优化逻辑**: 对含异丙基/偕二甲基的小分子芳香化合物放宽

```python
# 检查是否是芳香化单萜（含异丙基等萜类特征）
isopropyl = Chem.MolFromSmarts("[CH]([CH3])([CH3])")
gem_dimethyl = Chem.MolFromSmarts("[CH3][C]([CH3])([!H])[!H]")

if not (c_count <= 12 and has_terpene_feature):
    return False
```

**效果**:
- ✅ 香芹酚: 从False → True (正确识别)
- ✅ 百里酚: 仍需优化

### 4. 氧比例阈值调整 ✅

**优化逻辑**: 根据氧原子数量动态调整

```python
# 如果氧原子很多，放宽碳比例要求
if o_count > 5:
    min_c_ratio = 0.55  # 放宽到0.55
else:
    min_c_ratio = 0.65
```

**氧比例惩罚分级**:
```python
o_ratio = o_count / c_count
if o_ratio > 0.6:
    base_score *= 0.5  # 强惩罚
elif o_ratio > 0.5:
    base_score *= 0.7  # 中等惩罚
```

**效果**: 对环烯醚萜等高氧萜类更友好

### 5. 排除惩罚分级策略 ✅

**问题**: 原先所有排除模式都应用0.15惩罚，导致睾酮被误排除

**优化策略**:
```python
if name == 'carboxylic_acid':
    exclusion_penalty += 0.4  # 强惩罚
elif name in ['sugar_core', 'polyol', 'purine', 'pyrimidine', 'polyketide_like', 'phenylpropanoid']:
    exclusion_penalty += 0.3  # 强排除
elif name == 'fatty_acid_chain':
    exclusion_penalty += 0.05  # 弱惩罚（可能是萜类骨架的一部分）
else:
    exclusion_penalty += 0.15  # 中等惩罚
```

**效果**:
- ✅ 睾酮: selftest从失败 → 通过

## 仍存在的挑战

### 1. 高度氧化的萜类（环烯醚萜）
**案例**: 京尼平苷 (0.227)
- 含糖链
- 氧比例极高 (O/C = 0.59)
- 骨架匹配弱

**可能解决方案**:
- 添加环烯醚萜特征SMARTS
- 对含糖苷的分子放宽检测

### 2. 芳香化甾体（雌激素）
**案例**: 雌二醇 (0.347)
- A环芳香化
- 甾体骨架SMARTS可能不匹配芳香化变体

**可能解决方案**:
- 添加芳香化甾体SMARTS

### 3. 高度修饰的萜类
**案例**: 紫杉醇 (0.280)
- 多个酯基和芳香环取代基
- 碳/重原子比例降低
- 萜类特征被修饰掩盖

**可能解决方案**:
- 降低检测阈值到0.35
- 添加复杂萜类特征SMARTS

## 权衡与建议

### 当前配置特点
- **偏向精确率**: 阈值0.40，减少假阳性
- **羧酸强排除**: 萜类酸不被识别为萜类（学术上有争议）
- **适合一般用途**: 覆盖常见萜类，排除明显非萜类

### 可选调优方向

#### 选项1: 提高召回率（降低假阴性）
```python
terpenoid_threshold = 0.35  # 从0.40降到0.35
```
**效果**: 更多边界案例会被识别，但可能增加假阳性

#### 选项2: 放宽羧酸惩罚
```python
if name == 'carboxylic_acid':
    exclusion_penalty += 0.2  # 从0.4降到0.2
```
**效果**: 脱落酸等萜类酸会被识别，但可能误判真正的脂肪酸

#### 选项3: 添加更多骨架SMARTS
- 环烯醚萜核心
- 芳香化甾体
- 复杂萜类模式

**效果**: 提高特定子类识别，但增加模式库复杂度
